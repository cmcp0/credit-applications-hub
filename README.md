# Challenge Goal: 
## Build an MVP that allows users to: 

1. Create loan applications. 
2. Validate country-specific business rules. 
3. Integrate with different banking providers depending on the country. 
4. View individual applications. 
5. List applications filtered by country. 
6. Update the status of an application. 
7. Process business logic in the background and in parallel. 
8. Display information in (near) real-time on the front end.
